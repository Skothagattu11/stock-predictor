4 · Consensus aggregator + validation ~150 LOC in-house

Agreement scoring

Majority stance + agreement %. Models split → flagged as low conviction (divergence is a signal).

Number reconciliation

Any figure a model echoes is checked against the quant value — mismatch is stripped / re-asked. No hallucinated numbers reach the UI.

Headline + per-model rows

Consensus = headline; each provider's individual call stays expandable for side-by-side comparison.

Graceful degradation: no key / budget hit / all providers down → pure-quant templated output. The widget never errors.

LRU cache · TTL by horizon

Background trend tracker

Calibration log

Why this shape

Numbers in code

The LLM never does arithmetic — no hallucinated prices, fully cacheable, always degradable to pure-quant.

Models compared, not chosen

Same agent across every provider; consensus on top; disagreement surfaced as honest uncertainty.

Built to extend

OpenRouter

One more adapter + flag → 300+ models in the same ensemble. Off by default today.

Train your own model

Calibration log = labeled data; feature snapshot = input vector; serve it as one more adapter and benchmark it against the frontier models in the consensus panel.
